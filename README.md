# EAPF — Expert Medical Reference Platform

Адаптивная медицинская справочная платформа. Первый модуль — ингибиторы АПФ.

## Запуск локально
1. Установить Node.js LTS.
2. Выполнить `npm install`.
3. Выполнить `npm run dev`.

## Публикация
Проект рассчитан на Cloudflare Pages: команда сборки `npm run build`, папка результата `dist`.

## Медицинская безопасность
Демонстрационный интерфейс и начальный каталог не являются клиническими рекомендациями. Все медицинские сведения, дозировки, противопоказания и ссылки должны быть проверены профильным специалистом до клинического применения. Не вводите персональные данные пациентов.

## Supabase
SQL-схема находится в `supabase/schema.sql`. Для подключения задайте переменные из `.env.example`.
